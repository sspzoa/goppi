# 문서

고삐는 로컬 에이전트 하네스입니다. 풀스크린 TUI, 스크립트용 원샷 CLI, 알트 스크린을 끈 라인 REPL로 돌아갑니다. 바이너리 이름은 `goppi`입니다.

현재 기본 백엔드는 Upstage Solar입니다. [시작하기](user-guide/getting-started.md)부터 보고, 필요한 페이지로 이동하세요.

| 페이지 | 내용 |
|--------|------|
| [시작하기](user-guide/getting-started.md) | 설치, 첫 세션, 첫 프롬프트 |
| [인증](user-guide/authentication.md) | API 키 저장, 환경 변수, `login` / `logout` |
| [TUI](user-guide/tui.md) | 키, 슬래시 명령, 오버레이, 스트리밍 |
| [CLI](user-guide/cli.md) | 커맨드, 플래그, 셸 자동완성 |
| [설정](user-guide/configuration.md) | 파일, 환경 변수, 모델, effort |
| [세션](user-guide/sessions.md) | 이어가기, 내보내기, 저장 위치 |
| [툴](user-guide/tools.md) | 파일, bash, 문서, 권한 |
| [헤드리스](user-guide/headless.md) | `-p`, JSON, CI |
| [개발](development.md) | 빌드, 테스트, 레이아웃 |
