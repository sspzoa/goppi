# 문서

고삐는 한국형 에이전트 하네스입니다. 독자 foundation model이 있는 것처럼, 에이전트를 다루는 harness도 이 머신에 둡니다.

풀스크린 TUI, script용 one-shot CLI, alt-screen을 끈 line REPL로 돌아갑니다. 바이너리 이름은 `goppi`입니다.

현재 기본 backend는 Upstage Solar입니다. [시작하기](user-guide/getting-started.md)부터 보고, 필요한 페이지로 이동하세요.
