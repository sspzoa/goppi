# Documentation

goppi is a local coding agent on [Upstage Solar](https://console.upstage.ai/docs/capabilities/generate). It runs as a fullscreen TUI, a one-shot CLI for scripts, or a line REPL when you opt out of the alt screen.

Start with [Getting started](user-guide/getting-started.md), then open the page you need.
